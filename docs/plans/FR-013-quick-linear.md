# Native linear GPU text in Qt Quick

## Outcome and authority


Reproduce the accepted crisp masks and selected blend in a real OpenGL Qt Quick window and the installed Plasma applet host. Preserve ordinary UI colors, noneligible fonts, stock/inactive behavior, and accepted KWin/native-widget output. Provide a fresh native-size comparison.

The user accepts KWin, finds Qt Quick good overall, identifies OpenGL as chunkier, and requests all required continuation. The [roadmap](../roadmap.md) assigns GPU composition and fractional selection to FR-013. Carry the independent [KDE checks](../experiments/kde-paths.md), [FR-004 boundaries](FR-004-kde-paths.md), and [FR-014 profile correction](FR-014-a8-profile-scope.md) forward. The [composition research](../research/quick-composition.md) selects native sRGB operation rather than an alpha approximation.

Base: `50fdb18fc2a51e9783439b28cbe89d4d2b83620d`, main. Branch: `integration/qtquick-linear`, one writer in the existing checkout. FR-014 supplies the raster-profile supporting owner. This task promotes GPU composition, native per-run selection, and the existing opaque fractional reference into implementation. It does not promote transparent intermediate-target guarantees or arbitrary transforms.

Preserve callable signatures, virtual slots, existing enum values, and public class layouts. Mesa llvmpipe provides the deterministic baseline. The available Intel Mesa device can supply a separate physical-driver check. Other APIs and drivers do not inherit those results.

The floor is correct selected output on a verified compatible opaque target, preserved ordinary drawing, honest encoded fallback on an unsupported target, and process-local isolation. The ceiling excludes a replacement rasterizer, whole-scene gamma conversion, an automatic font/size policy, new persistent preferences, package installation, compositor restart, multisample correction, and guarantees for unknown/transparent targets. The arXiv search produced six isolated abstract reads with no direct Qt implementation. Native OpenGL specifications and actual Qt sources support the selected mechanism. An alpha-only fix lacks destination color information. A whole-scene sRGB flag changes ordinary colors. Draw-local conversion plus controlled storage/view handling is the smallest candidate that can satisfy both requirements. The phase contrast disproves unchanged vertex placement at a fractional half-pixel tie. Snap the shared eligible origin once before the retained shader, instead of changing the fitted quad or mask.

Reuse existing write-view metadata with a controlled ownership marker instead of changing all texture sampling or adding duplicate samplers.
